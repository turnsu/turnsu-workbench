# Turnsu 工作台

Turnsu 工作台是面向企业员工的本地 Agent 工作入口。连接偏好的 Agent，选择项目材料，明确授权，运行任务并核对真实成果；有效做法可以保存为 Skill 或本机定时任务。普通本地任务独立运行，团队共享与云端接入按需启用。

## 用户路径

1. 打开一个本地项目文件夹，用系统选择器导入资料，或在项目文件面板选择已有文件。导入保留原文件，项目副本放在 `Imported/`；同名文件不覆盖。
2. 在“连接 Agent”检查本机执行器或连接外部账号，然后在项目中试运行。模型网关单独配置；账号连接成功不等于模型推理或工具执行已通过。会话固定执行器及原生任务 ID。
3. 使用“能力与权限”准备官方文件包，选择允许读取的范围和独立输出目录。Excel、Word、PDF 由实际工具读取、生成和有限编辑；Office 转换/公式重算、OCR 可选启用。原件不覆盖，结果带来源位置与解析覆盖；项目中可查看内容预览或用系统应用检查版式。
4. 需要电脑操作时先选择隔离环境；本机已登录软件须另行确认应用与站点。界面可暂停、撤销及收取成果。沙盒不可用时不会切换成本机操作。
5. 将重复工作保存为本机计划：一次、按间隔、每日或每周。计划固定项目、Agent/连接、提示词、Skill 版本和授权；关闭窗口可留在托盘后台，明确退出后停止。错过的任务默认跳过，不连续补跑；结果不确定时先核对已有会话。

macOS 上可主动选择微信桥 v1 交接，核对原文和解析覆盖后在本机任务中引用。导入本身不调用模型、不上云、不发微信。Windows 可通过系统选择器导入授权导出的普通文件。扫描 PDF 需启用 OCR 并人工复核；不宣称自动理解所有图片、音频或复杂文档版式。

**本地工作台不等于离线模型。** Agent 若连接远程模型，会按其账号和配置发送输入。工作台也不能替客户已有 Agent 的全部原生工具设置强制统一沙箱。

## 开发

需要 Node.js ≥22.19；每个包保留自己的锁文件。原生 Agent CLI 与登录由用户配置，工作台不改写全局配置。

```sh
npm run setup
npm test
npm run build
npm start
```

`npm run package` 生成桌面开发包。桌面由 Electron、React 和私有 Node Host 组成；日常构建及自动测试在 Linux 开发机隔离目录进行。官方文件包和隔离电脑需要 Docker 兼容运行时；普通原生 Agent 不依赖 Docker、PostgreSQL 或托管接入服务。macOS 与 Windows 的系统交互和发行包需要各自实机验收。

| 路径 | 内容 |
| --- | --- |
| `apps/desktop` | 桌面界面、主进程和安全 IPC |
| `packages/agent-host` | 本机状态、原生 Agent 适配、资料与恢复 |
| `apps/team-web`、`services/product-api` | 可选团队管理与共享事项 |
| `packages` | 共享契约、客户端和运行模块 |
| `deploy`、`wiki` | 可选部署与现行文档 |
