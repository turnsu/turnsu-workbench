# Archived: Pre-M5 UI / UX 规范（原 `03`）

> 本文记录 2026-07-24 以前的页面规格。它在 M5 前端方向确定前编写，不再具有当前
> 产品、路由、创建流、模型选择或视觉验收权威；当前开发以
> `docs/rebuild/07-ux-restructure-m5.md` 和根目录 `DESIGN.md` 为准。保留本文仅为
> 追溯已完成的 M1–M3 工作，不得将其中规则重新带回 M5 实施或验收。

## 设计原则

1. **少即是多**：每个页面只有一个主行动按钮（primary action）。
2. **所有可见控件必须真实工作**（沿用 DESIGN.md 铁律）：按钮要么真实执行完整流程，
   要么禁用并说明原因和恢复路径，要么从 UI 隐藏。**不允许"即将推出"占位按钮**。
3. **所见即真实**：禁止演示数据、硬编码排序白名单、按名称静默过滤真实数据。
4. **Light-first**：浅色默认，克制的单一蓝色强调；沿用 DESIGN.md 与
   `wiki/design/skill-loop-cloud-workbench-v1/` 已选设计方向。
5. **反馈闭环**：toast 5 秒自动消失（错误 toast 可停留但可关闭）；危险操作统一
   一个确认对话框组件。
6. **增量收敛**：旧页面（Builder、Templates、Agent 等）在新 IA 验收通过前保持可访问；
   新页面通过验收后再切换默认导航，旧路由可保留一个版本周期后移除。

## 技术约束

- 保留现有栈：React 19 + Vite + TanStack Query + StyleX + lucide-react。不新增 UI 库。
- 目标路由：`/login` `/register` `/agent` `/skills` `/skills/:id` `/loops` `/loops/:id` `/members`。
  其余现有路由（builder、run-preflight、runs、loop-publish、library 等）**保留**
  直到 IA 验收（见"切换流程"）。`/agent` 已裁决为常驻任务入口（`07` D1）。
- 未登录访问任何页面 → 跳 `/login`。
- localStorage 只允许存 theme、locale。草稿回归服务端（删除 `editorDraftStorage.js`）。
- **模型选择 = 轻量共享开关**：composer/步骤配置旁的紧凑 chip + popover，按能力分组，
  前端只持有 `mode` + `modelProfileId`（规格见 `07` Batch A）。不再使用占版面的
  ModelPicker 面板形态；能力不变，只改表现层。
- **07 对本规范的部分取代**：Agent 工作区布局、Skill 创建向导、工作流创建分流、
  中文优先默认、高级设置折叠规则以 `07` 为准；本文件的页面骨架、交互铁律继续有效。

## 页面规格

### P0 登录 / 注册（`/login` `/register`）

- 单卡片居中：用户名、密码、提交按钮、互相跳转链接；错误内联显示。
- 注册页在系统无 admin 时显示一次性 bootstrap token 输入位；
  `WORKBENCH_REGISTRATION_OPEN=false` 时显示"注册已关闭，请联系管理员"。

### P1 Skill 库（`/skills`）

- 顶部：标题 + 唯一主按钮 **"上传 Skill"**。
- 列表（行列表，不用卡片）：名称、描述、最新版本、状态（草稿/已发布/已退役）、
  上传者、操作（查看）。
- 空状态：一句话 + 上传按钮 + 格式说明。
- **上传对话框**：两个 tab——"上传目录"（`webkitdirectory`，浏览器直传整个 Skill
  文件夹）和"上传 zip"。admin 额外看到第三个 tab"从服务器路径导入"（标注：
  仅管理员、扫描的是服务器本机目录，不是你自己电脑）。
- 无搜索/筛选/标签（V1.1 再说）。

### P2 Skill 详情（`/skills/:id`）

- 三区：说明（SKILL.md 渲染，含 `references/` 文件列表可展开）、版本列表、
  使用它的 Loop 列表。
- 操作：**发布**（草稿 → 不可变版本，版本号+说明；readiness 不过则禁用并列出原因）、
  **退役**（仅 admin，填原因，确认对话框）。
- MVP 无在线编辑器：修改 Skill = 改源文件后重新上传产生新草稿。

### P3 Loop 库（`/loops`）

- 顶部：标题 + 唯一主按钮 **"新建 Loop"**（名称+一句话目标，创建后进入工作台）。
- 列表：名称、目标、最新版本、状态、最近运行状态、更新时间；
  行操作：打开、Fork、删除（admin 或所有者，确认）。
- 看板拖拽视图删除，改纯列表。

### P4 Loop 工作台（`/loops/:id`，产品核心页）

```
┌──────────────────────────────────────────────────┐
│ 顶栏：Loop 名 | 状态 | [保存] [运行] [发布]        │
├────────────┬───────────────────────┬─────────────┤
│ Skill 面板  │      画布              │ 步骤配置     │
│ (拖入)     │  (节点+连线)           │ +ModelPicker│
├────────────┴───────────────────────┴─────────────┤
│ 底部抽屉：Run 历史 / 事件流 / 结果 / 待确认操作     │
└──────────────────────────────────────────────────┘
```

- **Skill 面板**（左）：已发布 Skill 列表，拖拽/双击入画布，可折叠。
- **画布**（中）：节点 = Skill，连线 = 数据流。删除节点用 undo toast（5s）——
  全产品统一这一种模式。保留并简化现有 `LoopCanvas`。
- **步骤配置**（右）：选中节点显示输入表单（按 SKILL.md inputs 生成）+ 上游输出引用
  + 轻量模型开关（chip+popover，见 `07` Batch A）；未选中显示 Loop 级 goal/doneWhen。
- **顶栏三动作语义严格区分**：
  - `保存`：新草稿 revision（etag 幂等）。
  - `运行`：编译 → 必填输入内联校验 → 启动 Run → 底部抽屉自动展开。
    （run-preflight 的校验能力保留，并入本页内联呈现，不独立成页。）
  - `发布`：当前 revision 有 ≥1 次成功 Run 才可点，否则禁用并注明原因。
    （loop-publish 独立页的 checklist 能力并入发布对话框。）
- **底部抽屉**：`运行记录`（状态/耗时/操作者/事件流/最终输出/重跑）+
  `待确认`（Tool Adapter 写操作确认项，复用 review decision 交互）。
- 同一页面**不允许出现两个 publish 按钮**（修复 `TemplatesBuilderView.jsx:337,496`
  的同 testid 双按钮问题）。

### P5 成员（`/members`）

- 列表：用户名、角色、注册时间、状态；admin 可禁用/启用、可变更角色（确认对话框）。
- 无邀请按钮（开放注册 + admin 关注册后手动开启覆盖）。

## IA 切换流程（防止"删了才发现要用"）

1. 新五页实现完成；
2. 对照走查：旧页面（builder/preflight/runs/publish/library/agent）的每个有效能力
   在新 IA 中有归宿（本规范 P1–P5 已列出映射）或明确决定保留入口；
3. 走查记录写入 `docs/rebuild/ia-acceptance.md`，列出每个旧路由的处置
   （合并/保留/移除）；
4. 切换默认导航；旧路由保留一个版本周期，挂 deprecation 横幅后移除。

## 交互铁律清单（验收逐条检查）

1. 全站一个确认对话框组件、一个 toast 组件（5s 自动消失，错误可停留可关闭）。
2. 每个禁用按钮必须有 tooltip 或相邻文字说明原因。
3. 异步操作有 loading 态；失败有可读错误文案映射（不直接暴露 `route_not_found` 原文）。
4. 表单必填项提交前内联校验，不用 alert。
5. 中英文双语，新增 i18n key 双语同时添加。
6. 生产 DOM 不允许隐藏测试按钮、游离 `aria-hidden` 标签、重复 `data-testid`；
   测试用语义定位（role/label）。
7. 危险三操作（删 Loop、退役 Skill、取消 Run）共用确认对话框，文案说明后果。
8. 画布节点删除 = undo toast（5s），全产品统一。
9. 写副作用操作（发消息/建任务等）执行前必须在 Run 内确认，不得一键直发。

## 明确不做的 UI

- 搜索 / 筛选 / 标签 / 分页器（V1.1）
- 拖拽排序看板
- 移动端 390px 适配（V1.1）
- 通知中心、全局搜索、快捷键体系
