# Skill OS 与 Loop

Skill OS 帮助用户找到、使用和沉淀可复用的方法。方法服务于当前项目和任务，不要求先理解执行引擎。

## Skill

读取项目中已有的 Skill，确认说明、来源、版本和所需权限，再在新任务中使用。也可以从已完成任务的实际回答创建方法草稿，检查文件与依赖后试用。保存方法不等于验证成功；安装与发布使用固定内容和版本。

项目文件和私有会话属于本机。向团队发布前必须核对要分享的文件与结果，不自动上传完整会话、隐藏上下文或凭据。云端状态不确定时查询已有回执，不能重复执行任务来补回执。

## Loop

Loop 是带顺序和依赖的重复方法。默认只显示名称、输入、步骤和结果。用户先试跑，再检查输出和失败位置，最后保存或发布版本。高级依赖与图形配置按需使用，不成为日常任务的前置步骤。

继续保留版本固定、停止 / 恢复、权限、安装一致性和结果核验。精简界面不能取消这些保障。新项目不预装行业业务样例。
