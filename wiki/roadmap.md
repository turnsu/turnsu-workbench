# 迭代路线

## 当前迭代

收敛本地原生 Agent 工作台：清理失效实现与文档，桌面独立构建，保留 Skill OS / Loop 与可选团队协作；会话按项目分页，历史按需读取，闲置连接可回收。先核对现有会话、草稿、文件与凭据，再验证任务恢复。

## 下一步验收

1. 在 macOS 和 Windows 上使用真实 Pi、Claude Code、Codex，覆盖任务执行、权限请求、停止、重开与恢复。
2. 对真实模型连接分别验证目录、推理、流式输出、鉴权失败和断线恢复；不把兼容协议名称当作供应商已通过验证。
3. 用大量历史与长时间连续任务测量完整进程组的内存趋势，定位增长所有者，再决定是否需要进一步隔离或替换底层组件。
4. 在同一黄金路径中继续打磨 Skill 使用、方法试跑与简明 Loop 交互；团队能力按显式分享需求接入。

后续每项以用户可见结果和真实验收为终点，不默认新增业务模块、兼容框架或新服务。
