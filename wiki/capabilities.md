# 工作台能力扩展

本轮已确认范围：Turnsu 托管 WorkBuddy 与 Muse 接入服务；Manus API v2；多原生 Agent 工具接入；Excel、Word、PDF 能力包；默认隔离的 CUA；仅本机后台定时。本文为实现约束，不代表各项已通过真实账号或设备验收。

## 用户路径

连接 Agent → 选择项目材料 → 明确执行位置与权限 → 运行并检查真实成果 → 保存 Skill 或定时任务。连接引导与模型网关分开。连接器不可用时保留草稿并说明恢复步骤，不换 Agent。

## 接入合同

- WorkBuddy：应用密钥与刷新凭据仅保存在 Turnsu 服务端。基础权限为本地助理读取与调用，云端任务权限另行申请；不默认申请手机号和积分权限。按原生消息或任务 ID 恢复。未核验的审批、停止、设备与目录绑定能力显示限制。
- Manus：API v2、客户 API Key 存系统凭据库；Team 授权使用 PKCE。保留任务 ID、增量消息与文件回执；任务仍有后台作业时不提前完成。
- Muse：个人助理双向交接，首次在 Muse 确认接手。连接器只读取获准任务，可回传进展、成果及本机操作请求；本机执行仍受工作台授权。未公开的原生会话启动不能伪装成自动接入。
- 本机 Agent：Kimi、Codex、OpenCode、oh-my-pi、Pi 按各自协议声明工具能力。Claude Code 保留但本轮真实测试暂缓。MCP/扩展配置为当前工作台执行专用，不修改客户全局配置。

## 文件与电脑操作

官方文件包使用独立、锁定版本的 Python 环境，提供 Excel/Word/PDF 读取、生成和有限编辑。返回工作表、单元格、段落/页码与解析覆盖；公式缓存不是重算，扫描页不是已读文本。输入原件不变，输出为新文件；转换/重算、OCR 是单独的可选依赖。

Skill 只提供方法。能力包声明版本、依赖、权限；权限扩大需要重新授权。工具调用在 Host 中检查项目、资源、执行目标、有效期及撤销状态。

电脑操作默认隔离，运行时/镜像固定版本，输入只读、输出独立，限制 CPU、内存、进程和网络。访问本机已登录软件须选择本机模式及应用/站点；可停止和撤权。Cua Driver 使用 bounded 模式，缺少有效清单即拒绝启动。沙盒不可用时引导修复，不静默退回本机。自带 Agent 的其他原生工具并不会因此受到工作台沙盒控制。

## 本机后台

一次、间隔、每日、每周计划固定项目、Agent/连接、方法版本及权限。每次产生独立输入快照和执行记录。同计划不重叠；默认跳过错过时刻，可选只补最近一次。重启先核对已有执行，不重放不确定写入。

关闭窗口可保留托盘后台；明确退出停止调度；登录自启为用户选择。新权限进入等待批准。历史、文件和截图按需读取；解析、沙盒和原生进程纳入完整资源测量。

## 验收

Linux 开发机承担自动化和沙盒测试；macOS/Windows 分别验收可见交互、权限、文件、恢复与升级。真实连接测试与可控协议测试分别记录。至少包含文档结构/公式/扫描页、源文件不变、凭据撤销与跨客户隔离、重复提交、断线恢复、越权、锁屏、休眠、夏令时、重复启动及长时资源回收。应用审核或账号不足不以模拟测试补成已通过。

当前实现和验证分层见 [README 能力矩阵](../README.md#当前状态)与[验证记录](verification.md)。Linux 已运行真实文件容器、原生 CLI 到工具的回合，以及隔离浏览器操作和强制崩溃回收。托管连接器的数据库、HTTP 和协议替身测试不能证明平台应用已经获批；Muse 官方连接器适配仍未完成。macOS 锁屏时不计新增界面验收，Windows 无设备时不以构建替代交互结论。
