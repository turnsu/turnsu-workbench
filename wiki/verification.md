# 验证记录

2026-09-28，针对当前目录结构、桌面独立构建、会话分页和原生连接回收进行验证。测试使用隔离目录、临时 SQLite 和专用 PostgreSQL 测试数据库；没有删除用户原生会话或凭据。

## 本轮 Linux 开发机验证

在 turnsu Linux 开发机使用隔离目录和一次性 Node 22 容器，未安装桌面应用，也未连接现有企业服务。`packages/agent-host` 全量测试 **136/136 通过**；`apps/desktop` 逻辑测试 **4/4 通过**，桌面 UI 与私有 Host 构建通过。测试涵盖本机 Agent 偏好持久化、微信桥 v1 合成交接的完整性校验、项目隔离、并发导入、崩溃后本机快照恢复，以及共享文件避免重复读取、修改后同步、定期复核与自动同步并发上限。

这些测试使用合成交接和受控团队服务替身，证明代码路径及持久化行为，不证明 macOS 实际微信分享、客户业务回执、原生 Agent 登录 / 推理或 Linux 桌面可见交互。Linux 开发机没有可用的图形会话，本轮没有重复安装 Mac 包。

## 合成历史负载

通过 `node packages/agent-host/test/benchmark-history.mjs` 启动真实独立 Host 与 SQLite。选中会话含 2,400 条消息，约 9 MB 文本；未启动原生 Agent、Renderer 或真实模型。`TURNSU_BENCH_SESSIONS` 分别设置为 20 和 10000。

| 指标 | 20 条会话 | 10,000 条会话 |
| --- | ---: | ---: |
| 启动响应 | 461 字节 / 0 条会话 | 461 字节 / 0 条会话 |
| 项目索引响应 | 3,751 字节 / 20 条 | 7,371 字节 / 40 条 |
| 当前消息响应 | 165,786 字节 / 40 条 | 165,786 字节 / 40 条 |
| Host RSS：读取前 | 104,768 KiB | 107,184 KiB |
| Host RSS：读取五次后 | 107,888 KiB | 110,336 KiB |

这是同一机器上的单次合成对照，证明当前查询和传输的范围受控。RSS 仅包含 Host，不能推断完整桌面的长时内存趋势，也不能证明与其他产品相比占用更低。
