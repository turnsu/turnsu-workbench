# 验证记录

## 2026-09-30：跨环境 CI 与真实 Worker 验证

在 turnsu Linux 开发机的隔离目录中，用 Node 22 和真实 Docker 镜像复测：本地 Host 与桌面逻辑测试通过；Agent runtime、团队服务与 Web 测试通过；隔离 PostgreSQL 全流程（含 Skill 上传与读取）通过，容器及测试卷由运行器清理。10,000 条会话、单会话 2,400 条消息的独立 Host 验证返回启动 0 条、索引 40 条、历史 40 条，五次读取后 RSS 增长 2,932 KiB。该值是 Linux 单次 Host 测量，不代表桌面完整进程组的长期占用。

Worker 镜像构建后，真实非特权容器通过 Pi 会话及动态子任务两条路径：产品侧网关执行合成模型调用，结果进入执行记录，会话记录保存，子任务在父任务完成前进入时间线。测试曾发现容器写入目录受宿主 umask 阻挡、容器 UID 与宿主 UID 不同导致临时目录无法清理；修复后同一真实测试通过。模型响应仍是受控替身，没有客户凭据或生产模型调用。macOS、Windows 的 Actions 结果及桌面可见交互需单独核对，不能由 Linux 结果推断。

在 turnsu Linux 开发机使用隔离目录和一次性 Node 22 容器，未安装桌面应用，也未连接现有企业服务。`packages/agent-host` 全量测试 **136/136 通过**；`apps/desktop` 逻辑测试 **4/4 通过**，桌面 UI 与私有 Host 构建通过。测试涵盖本机 Agent 偏好持久化、微信桥 v1 合成交接的完整性校验、项目隔离、并发导入、崩溃后本机快照恢复，以及共享文件避免重复读取、修改后同步、定期复核与自动同步并发上限。

## 合成历史负载

通过 `node packages/agent-host/test/benchmark-history.mjs` 启动真实独立 Host 与 SQLite。选中会话含 2,400 条消息，约 9 MB 文本；未启动原生 Agent、Renderer 或真实模型。`TURNSU_BENCH_SESSIONS` 分别设置为 20 和 10000。

| 指标 | 20 条会话 | 10,000 条会话 |
| --- | ---: | ---: |
| 启动响应 | 461 字节 / 0 条会话 | 461 字节 / 0 条会话 |
| 项目索引响应 | 3,751 字节 / 20 条 | 7,371 字节 / 40 条 |
| 当前消息响应 | 165,786 字节 / 40 条 | 165,786 字节 / 40 条 |
| Host RSS：读取前 | 104,768 KiB | 107,184 KiB |
| Host RSS：读取五次后 | 107,888 KiB | 110,336 KiB |

这是同一机器上的单次合成对照，证明当前查询和传输的范围受控。RSS 仅包含 Host，不能推断完整桌面的长时内存趋势，也不能证明与其他产品相比占用更低。

本轮在同一 Linux Node 22 隔离容器中复测相同规模，基准脚本通过 `/proc/<pid>/status` 读取子进程 RSS，无需额外安装系统工具。每组都只在一个选中会话中放入 2,400 条合成消息，分别启动独立 Host；下表是单次值，不用于跨系统性能比较。

| 指标 | 20 条会话 | 10,000 条会话 |
| --- | ---: | ---: |
| 启动响应 | 545 字节 / 0 条会话 | 545 字节 / 0 条会话 |
| 项目索引响应 | 3,835 字节 / 20 条 | 7,455 字节 / 40 条 |
| 当前消息响应 | 165,778 字节 / 40 条 | 165,778 字节 / 40 条 |
| Host RSS：读取前 | 104,588 KiB | 104,332 KiB |
| Host RSS：读取五次后 | 106,304 KiB | 107,060 KiB |

不同运行间的少量 RSS 差异是单次测量波动；本测试没有启动 Electron、原生 Agent 或模型，也没有覆盖 100,000 条分布在多会话的消息、8 小时运行或归档解析峰值。
